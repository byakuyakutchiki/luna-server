# LUNA — Script Vidéo de Présentation

**Durée estimée : 2min30 — 3min**
**Ton : chaleureux, moderne, accessible. Pas de jargon. Un enfant de 10 ans comprend.**
**Musique : lo-fi chill ou piano ambient léger, jamais au-dessus de la voix**

## NOTES DE PRODUCTION

### Captures d'écran nécessaires (dans l'APK)
1. Écran de login → transition vers le chat
2. Chat : envoyer un message, Luna répond (typing dots → réponse)
3. Chat : demander un rappel → Luna confirme
4. Bouton Appel Vocal → téléphone qui sonne
5. Bouton Visio → cinématique complète (nuit de préférence, c'est la plus belle)
6. Onglet Perception : caméra ouverte, analyse en cours
7. Onglet Contacts : liste avec badges relation
8. Monde de Luna : vue générale (nuit pour les lucioles), clic sur bâtiment, badge débloqué
9. Onglet Amis : code ami, liste amis, DM
10. Groupe familial + SOS
11. Luna qui dit "Bonne nuit"

### Voix off
- **Ton** : posé, chaleureux, ni commercial ni clinique. Comme si tu expliquais l'app à un pote.
- **Rythme** : pas pressé. Laisser respirer entre les phrases.
- **Pas de** : "intelligence artificielle", "algorithme", "machine learning", "senior", "personnes âgées", "dépendance"
- **Utiliser** : "compagnon", "amie", "elle comprend", "elle se souvient", "elle est là"

### Musique suggestions
- Lo-fi beats doux
- Piano ambient (type Nils Frahm)
- Pas de voix dans la musique
- Baisser la musique sur les moments forts (visio cinématique, closing)
