OpenAI — L'intelligence de Luna

Luna utilise OpenAI pour comprendre et repondre a vos clients

  1. Ouvrez platform.openai.com
  2. Creez un compte (ou connectez-vous)
  3. Allez dans Settings > Billing et ajoutez une carte bancaire
  4. Allez dans API Keys > Create new secret key
  5. Copiez la cle (elle commence par sk-)
Commence par 'sk-'. Ne la partagez jamais.

Twilio — L'envoi de SMS

Twilio permet a Luna d'envoyer des SMS a vos clients et leurs proches

  1. Ouvrez twilio.com
  2. Creez un compte et passez en mode payant
  3. Achetez un numero de telephone (~1 EUR/mois)
  4. Sur le Dashboard, copiez : Account SID, Auth Token, et le numero achete
Le numero que vous avez achete, commence par '+'

Stripe — Les paiements

Stripe gere les abonnements de vos clients

  1. Ouvrez stripe.com
  2. Creez un compte professionnel
  3. Allez dans Developers > API Keys
  4. Copiez la Secret Key
Commence par 'sk_test_' (test) ou 'sk_live_' (production)
Configuration webhook :
  1. Stripe Dashboard → Developers → Webhooks
  2. Cliquez "Add endpoint"
  3. URL : https://VOTRE_DOMAINE:8888/api/stripe/webhook
  4. Events : customer.subscription.*, invoice.*
  5. Copiez le "Signing secret" (whsec_...)

Creation des 3 formules — Luna va creer automatiquement vos produits Stripe :

  • Essentiel — 79 EUR/mois
  • Confort — 149 EUR/mois
  • Premium — 249 EUR/mois

Tavus — L'avatar video

Tavus permet a Luna d'apparaitre en video (mode Full uniquement)

Mode Lite selectionne — Tavus n'est pas necessaire.
  1. Ouvrez tavus.io
  2. Creez un compte Business
  3. Generez une API Key
  4. Creez une persona 'Luna' et copiez le Persona ID
