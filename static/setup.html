OpenAI — L'intelligence de Luna

Luna utilise OpenAI pour comprendre et repondre a vos clients

▶Comment obtenir votre cle API OpenAI▼
  1. Allez sur platform.openai.com
  2. Connectez-vous ou creez un compte
  3. En haut a droite : icone profil → API Keys
  4. Bouton Create new secret key → nommez-la "Luna" → Create
  5. ⚠ Copiez IMMEDIATEMENT la cle (elle ne sera plus jamais visible)
  6. Si erreur "billing" : Settings → Billing → Add payment method
Commence par 'sk-'. Ne la partagez jamais.
💡
Conseil de LunaChoisissez gpt-4o-mini pour commencer : c'est 20x moins cher que gpt-4-turbo et suffisant pour 90% des conversations.

Twilio — L'envoi de SMS

Twilio permet a Luna d'envoyer des SMS a vos clients et leurs proches

▶Comment configurer Twilio (SID + Token + Numero)▼
  1. Allez sur console.twilio.com
  2. Sur le dashboard : Account SID et Auth Token sont affiches directement
  3. Copiez les deux valeurs
  4. Menu gauche → Phone Numbers → Buy a Number
  5. Filtrer par pays : France (+33) → choisir un numero → Buy
  6. Le numero apparait dans TWILIO_SMS_FROM
Le numero que vous avez achete, commence par '+'
💡
Conseil de LunaAchetez un numero francais (+33) pour que vos clients reconnaissent l'expediteur. Un numero US coute moins cher mais les SMS arrivent souvent en spam.

Stripe — Les paiements

Stripe gere les abonnements de vos clients

▶Comment configurer Stripe (API + Webhook)▼
  1. Allez sur dashboard.stripe.com
  2. Menu → Developers → API Keys
  3. Copiez la Secret key (sk_test_... ou sk_live_...)
  4. Pour le webhook : Developers → Webhooks → Add endpoint
  5. URL : https://votre-serveur:8888/api/stripe/webhook
  6. Events : checkout.session.completed, customer.subscription.*, invoice.payment_failed
  7. Copiez le Signing secret (whsec_...)
Commence par 'sk_test_' (test) ou 'sk_live_' (production)
Configuration webhook :
  1. Stripe Dashboard → Developers → Webhooks
  2. Cliquez "Add endpoint"
  3. URL : https://VOTRE_DOMAINE:8888/api/stripe/webhook
  4. Events : customer.subscription.*, invoice.*
  5. Copiez le "Signing secret" (whsec_...)

Creation des 3 formules — Luna va creer automatiquement vos produits Stripe :

  • Essentiel — 79 EUR/mois
  • Confort — 149 EUR/mois
  • Premium — 249 EUR/mois
💡
Conseil de LunaCommencez en mode TEST (sk_test_) pour tout configurer sans risque. Passez en LIVE (sk_live_) uniquement quand tout est pret.

Tavus — L'avatar video

Tavus permet a Luna d'apparaitre en video (mode Full uniquement)

Mode Lite selectionne — Tavus n'est pas necessaire.
▶Comment configurer Tavus (API + Persona)▼
  1. Allez sur dashboard.tavus.io
  2. Menu → API Keys → Generate Key
  3. Copiez la cle API
  4. Menu → Personas → votre persona Luna
  5. Copiez le Persona ID (commence par p)
💡
Conseil de LunaLe plan Starter Tavus ($59/mois, 100 min) suffit jusqu'a 30 clients. Prevoyez le Growth ($397/mois) au-dela.
