Telecharger Luna.apk v2.2 - Proprio

Installation sur Android :

  1. Telecharge le fichier luna-proprio.apk
  2. Ouvre le fichier telecharge
  3. Android demande "Autoriser l'installation de sources inconnues" → Autoriser
  4. Clique Installer
  5. Ouvre Luna depuis l'ecran d'accueil

L'app se connecte automatiquement au serveur Luna.
Les mises a jour se font automatiquement depuis l'app.
Camera et micro sont necessaires pour la visio et le wake word.
