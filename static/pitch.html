Comment vous branchez Luna Exploitant

# 1. Cloner le package exploitant
git clone https://github.com/byakuyakutchiki/luna-exploitants

# 2. Configurer vos clés API
cp .env.template .env
nano .env # OPENAI_API_KEY, TWILIO, STRIPE...

# 3. Lancer avec Docker
docker-compose up -d

# 4. Wizard de setup automatique
python wizard_install.py
